# Instruções para o Claude Code neste repositório

## Design

Antes de qualquer mudança de interface, ler o `DESIGN.md` e segui-lo. Sem cores, tamanhos ou
espaçamentos escritos direto nas telas; usar as variáveis e componentes do design system. Quando
uma decisão visual mudar, atualizar o `DESIGN.md` na mesma PR.
